# .NET MAUI Basics - Complete Beginner Course

**Welcome to .NET MAUI!** This course will take you from zero to building your first cross-platform mobile application.

## 📚 Course Overview

.NET MAUI (Multi-platform App UI) is Microsoft's framework for building native mobile and desktop applications with a single codebase. Write once, deploy to:
- 📱 Android
- 🍎 iOS
- 🪟 Windows
- 🖥️ macOS (Mac Catalyst)

## 🎯 What You'll Learn

1. **Setup & First App** - Install tools and create your first MAUI application
2. **XAML Fundamentals** - Build user interfaces with declarative markup
3. **MVVM Pattern** - Master the Model-View-ViewModel architecture
4. **Data Binding** - Connect UI to data seamlessly
5. **Navigation** - Move between screens in your app
6. **Dependency Injection** - Manage services and dependencies
7. **Platform-Specific Code** - Handle differences between platforms
8. **Local Storage** - Save data with SQLite
9. **API Integration** - Connect to web services
10. **Deployment** - Publish your app to stores
11. **SQLite Basics** - Deep dive into local database operations
12. **REST APIs** - Master HTTP requests and API communication
13. **Serialization** - Convert objects to/from JSON
14. **Custom Renderers** - Extend controls with platform-specific code (ADVANCED!)
15. **Effects** - Add lightweight visual enhancements (ADVANCED!)
16. **Animations** - Create smooth, engaging UI animations (ADVANCED!)

## 🎓 Prerequisites

Before starting this course, you should have:

- ✅ Basic understanding of C# (variables, methods, classes)
- ✅ Familiarity with object-oriented programming concepts
- ✅ A Windows PC with Visual Studio 2022 (or Mac with VS for Mac)

## 🛠️ What You'll Build

Throughout this course, you'll build a **Simple Notes App** that demonstrates all key MAUI concepts:

- Save notes locally with SQLite
- Navigate between screens
- Use MVVM pattern properly

1. **Install Visual Studio 2022 Community** (free)
   - During installation, check ".NET MAUI" workload
   - This installs all necessary tools and emulators

2. **Verify Installation**
   - Open Visual Studio
   - Create new project
   - Search for ".NET MAUI" templates

3. **Start Lesson 1** - [Introduction to MAUI](01_Introduction_to_MAUI.md)

## 💡 Tips for Success

- **Follow Along**: Type the code yourself, don't just copy-paste
- **Experiment**: Modify examples and see what happens

- **Build Projects**: Apply what you learn to small projects
